# momo

مستودع Python صغير يحتوي حاليًا على الملف `moha.py` فقط. يعرض المصدر تطبيقًا لإنشاء وإدارة بوتات تواصل فرعية على Telegram، مع استقبال الرسائل وتمريرها إلى إدارة البوت والرد على المستخدمين. هذه قراءة وصفية للشيفرة وليست تأكيدًا على أن المشروع يعمل أو جاهز للاستخدام.

## محتويات المستودع

- `moha.py` — نقطة الدخول الوحيدة الظاهرة في المستودع، وتضم منطق المصنع والبوتات الفرعية وحفظ بياناتها.

لا يحتوي المستودع على README سابق أو ملف متطلبات قياسي؛ كما لم يظهر في الشجرة ملف إعداد منفصل أو اختبارات.

## الوظائف الظاهرة في المصدر

تتضمن الشيفرة، بحسب تعريفاتها ومعالجاتها، ما يلي:

- واجهة مصنع لإضافة بوتات فرعية وإدارتها وعرضها وحذفها.
- تشغيل كل بوت فرعي بنمط الاستطلاع (polling)، واستقبال رسائل المستخدمين وتمريرها إلى الإدارة وإرسال الردود إليهم.
- أدوات إدارة تشمل الحظر وإلغاء الحظر والكتم وإلغاء الكتم وإدارة المشرفين الفرعيين.
- إعدادات للبوت الفرعي مثل رسالة الاستلام، رسالة الترحيب وصورتها، وأنواع الوسائط أو الروابط المحظورة.
- إرسال رسائل أو محتوى إلى مجموعة من المستخدمين، وإرسال/تمرير رسائل إدارية.
- فحص اشتراك المستخدم في قناة وإدارة قنوات المصنع، إضافة إلى إجراء نسخ احتياطي للبيانات.

هذه قائمة بما يظهر في الملف، ولا تثبت اكتمال كل مسار أو نجاحه في بيئة فعلية.

## المتطلبات والإعداد

- يلزم مفسر Python؛ لا تحدد الملفات إصدارًا أدنى موثوقًا.
- يستورد المصدر مكتبات منها `telebot` و`requests` و`psutil`، لكن لا يوجد `requirements.txt` أو ملف قفل يحدد التبعيات وإصداراتها.
- ينفذ المصدر تثبيتًا أو ترقيةً للتبعيات وقت بدء التشغيل باستخدام `pip`. لذلك قد يغيّر بيئة Python تلقائيًا ويتطلب اتصالًا بالشبكة. لا تشغّله في بيئة مهمة أو متصلة ببيانات حساسة قبل مراجعة هذا السلوك وتأمينه.
- لم يظهر في المصدر استخدام لمتغيرات بيئة موثقة. لا توجد خطوات إعداد آمنة مكتملة يمكن تأكيدها من الملفات الحالية.

## التشغيل

يحتوي الملف على نقطة دخول عند تشغيله مباشرة، ويمكن استنتاج الأمر التالي من بنية المصدر فقط:

```bash
python moha.py
```

**هذا الأمر غير مجرّب، ولا يُنصح بتنفيذه قبل معالجة ملاحظات الأمان أدناه.** يبدأ الملف بتثبيت/ترقية تبعيات وقت التشغيل، كما يعتمد على توكنات بوتات وبيانات محفوظة محليًا. لم يُشغّل المشروع أو تُثبت تبعياته أثناء إعداد هذه الوثيقة.

## البيانات والسلوك التشغيلي

تُحفظ بيانات البوتات في `bots_data.json` بصيغة JSON، وتشمل بيانات إعداد وبوتات فرعية. يستخدم البرنامج استطلاع Telegram، لذا يحتاج تشغيله إلى اتصال بالشبكة وإلى أن تظل العملية عاملة. وقد يتضمن النسخ الاحتياطي إرسال البيانات عبر Telegram؛ تعامل مع النسخة الاحتياطية كملف حساس.

## الأمان والخصوصية

- لاحظ تقرير التدقيق احتمال وجود توكن ثابت للمصنع في المصدر. لا تنشر أي توكن، وأبطل أو دوّر أي توكن سبق تضمينه في الشيفرة أو انكشف.
- توكنات البوتات المحفوظة في `bots_data.json` غير مشفرة بحسب المراجعة الساكنة. قيّد صلاحيات الوصول إلى الملف، ولا ترفعه إلى مستودع عام أو ترسله دون حماية، واحذف النسخ غير اللازمة بطريقة آمنة.
- راجع وجهة النسخ الاحتياطية ومن يستطيع الوصول إليها؛ قد تكشف البيانات المحفوظة صلاحية التحكم بالبوتات.
- ميزة الإذاعة الجماعية قد تُستخدم لإرسال رسائل غير مرغوبة أو تتسبب في قيود من Telegram. استخدمها فقط لمستلمين وافقوا على التواصل، والتزم بشروط Telegram والقوانين المعمول بها.
- قبل أي استخدام، أزل الأسرار المضمّنة وانقلها إلى آلية إدارة أسرار مناسبة، وأوقف تثبيت/ترقية الحزم تلقائيًا وقت التشغيل أو راجعه وثبّت التبعيات بإصدارات معلومة في بيئة معزولة.

المستودع يتكون من ملف مصدر واحد دون ملف تبعيات أو اختبارات أو توثيق تشغيل. لم تُشغّل الشيفرة أو الاختبارات، ولم تُثبت أي اعتماديات؛ لذلك لا يوجد تأكيد على نجاح الإعداد أو بدء البوتات أو صحة مسارات الإدارة والنسخ الاحتياطي. يلزم إجراء مراجعة واختبارات أمنية وتشغيلية مستقلة قبل استخدامه مع حسابات أو بيانات حقيقية.
